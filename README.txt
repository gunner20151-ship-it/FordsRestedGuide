========================================================================
                 FORD'S RESTEDGUIDE v10.0 (WoW: Forever)
          All-Horde 1-60 Smart Auto-Syncing Leveling & Quest Guide
========================================================================

HOW TO INSTALL:
1. If you downloaded this .zip from Discord or a browser, right-click
   "FordsRestedGuide_v10.0.zip" -> Properties -> check "Unblock" (if shown) -> OK.
2. Extract the "FordsRestedGuide" folder into your WoW: Forever AddOns directory:
   ...\World of Warcraft\_forever_\Interface\Addons\FordsRestedGuide
3. Launch WoW: Forever, click "AddOns" on the Character Selection screen,
   and ensure "Ford's RestedGuide" is checked.

------------------------------------------------------------------------
KEY FEATURES:
- All 5 Horde Races Supported (1-60): Auto-detects Windshaper Skyborne
  (Zephras Isle), Undead (Tirisfal), Orc (Durotar), Troll (Durotar), and
  Tauren (Mulgore) starter zones and merges into the 13-60 WoW: Forever route
  (Ruins of Lordaeron, City of Dalaran, The Drowned City, The Riverglades,
  Krol'dok Stronghold, Shen'dralas, Alcaz Prison, Blackmaw Hold, and
  The Shaper's Terrace).
- Smart Auto-Sync: Reads your character level, race, class, active Quest Log,
  and server-completed quests to jump straight to your current step!
- Interactive Quest Checklists: Click any quest in the list to lock the 3D
  Waypoint Arrow and "Target NPC" button onto that specific quest!
- Optional Class Quests: Auto-detects all 9 Horde classes (Warrior, Mage,
  Warlock, Rogue, Priest, Shaman, Hunter, Druid, and Undead Paladin) and shows
  class quests with Available vs. Recommended levels.
- Built-in Hearthstone Button, Flight Path Reminders, Optional Auto-Quest
  Accept/Turn-In, and Live XP/Hr + Time-to-Level tracker.

------------------------------------------------------------------------
CONTROLS & SLASH COMMANDS:
- Minimap "FW" Icon:
  * Left-Click:   Show / Hide Guide Window
  * Right-Click:  Open Settings Menu
  * Middle-Click: Run Smart Auto-Sync
  * Left-Drag:    Move icon around the Minimap ring

- In-Window Controls:
  * Click any Quest Row: Lock/unlock the 3D arrow & Target button to that quest
  * Shift + MouseWheel:  Flip forward/backward through steps quickly
  * "Cfg" Button:        Open Settings (Lock window, Scale, Opacity, Toggles)
  * "-" / "+" Button:    Collapse / Expand window during dungeons

- Slash Commands:
  * /frg          - Toggle the guide window
  * /frg config   - Open the Settings menu
  * /frg sync     - Run Smart Auto-Sync
  * /frg step #   - Jump directly to step # (e.g., /frg step 8)
  * /frg reset    - Reset guide back to Step 1
